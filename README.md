# Portfolio de Víctor Touriño Fernández

Portfolio personal para presentar mi perfil, proyectos y experiencia a empresas que ofrezcan prácticas o un puesto junior de desarrollo de software.

**Web publicada:** [https://victortourinoportfolio.github.io/](https://victortourino.github.io/VictorTourinoPortfolio/)

## Qué incluye

- Presentación, objetivo profesional y modalidad de trabajo buscada.
- Proyectos con su stack y enlace al código: TuPadel, gestion-usuarios-java-swing, trading-transactions-tracker y VirtuBroker (en desarrollo).
- Experiencia profesional en una línea temporal.
- Stack técnico, formación e idiomas.
- Descarga del CV en PDF.
- Selector de idioma español / inglés. El idioma se guarda en el navegador y el predeterminado es el español.

## Tecnologías

- HTML5 semántico.
- CSS3 con variables, Grid y Flexbox. Es responsive y respeta el modo oscuro del sistema (`prefers-color-scheme`) y la preferencia de movimiento reducido.
- JavaScript sin dependencias ni frameworks. Gestiona las traducciones y los enlaces de contacto desde un único objeto `CONFIG`.
- Iconos del stack desde [Devicon](https://devicon.dev/) por CDN. Si no cargan, el nombre de la tecnología sigue visible.
- Alojada en GitHub Pages.

## Estructura del proyecto

- `index.html`: contenido y estructura de la página.
- `styles.css`: estilos, tema claro y oscuro, y diseño responsive.
- `script.js`: traducciones ES/EN, selector de idioma y enlaces configurables.
- `docs/`: CV en PDF y mi foto
